# Concepção do software
Esse projeto foi desenvolvido para um atividade da disciplina Inteligência Computancional, na qual foi estudada a lógica Fuzzy e a implementação em Python

Portanto, para a concepção do programa foi utilizado Python com algumas bibliotecas, com menção honrosa ao $\color{purple}{MySQL \space Connector}$, $\color{purple}{PyQt6}$ e $\color{purple}{Scikit-Fuzzy}$
Ademais, durante o desenvolvimento da interface gráfica também foi feito o uso do Qt Designer

# Interfaces gráficas
- Página inicial
- Página para computar nova apuração
- Página para acessar o histórico de apurações
- Sobre

# Como utilizar
É possivel utilizar o repositório diretamente no VS Code. Contudo, é recomendável fazer alterações nos campos em que há manipulação do banco de dados, em outras palavras, nas linhas em que é preciso definir as suas próprias credenciais do MySQL
